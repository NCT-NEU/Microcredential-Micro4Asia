## Python programming for data science
<hr>

### MP Title

Python programming for data science  
- Class contact: 15 hours  
- Independent study: 30 hours

---

### MP Aim

Develop foundational Python programming skills for data handling and automation, with a strong focus on core programming constructs and the practical use of NumPy and Pandas for structured data manipulation.

---

### Learning outcomes 

| LO code | Bloom Level | Category | Learning outcome |
|---------|-------------|----------|------------------|
| LO.1 | Understand | Knowledge | Explain the role of Python programming in data science and its advantages over manual data processing. |
| LO.2 | Understand | Knowledge | Describe the structure and functionality of NumPy arrays and Pandas DataFrames. |
| LO.3 | Apply | Skills | Use core Python syntax and control structures to perform basic data operations. |
| LO.4 | Apply | Skills | Apply NumPy for numerical computation and array-based data manipulation. |
| LO.5 | Apply | Skills | Use Pandas to read, modify, and organize structured datasets. |
| LO.6 | Apply | Skills | Implement basic data workflows combining Python, NumPy, and Pandas. |

---

### Content

| Topic No. | Teaching topic | Content description | LO |
|-------|----------------|--------------------------------|---------|
| 1 | Introduction to Python programming | Overview of Python for data science.<br>Python environment setup and Jupyter Notebook usage.<br>Basic syntax, variables, data types, and operators. | LO.1, LO.3 |
| 2 | Core programming constructs | Conditional statements and loops.<br>Functions and modular programming.<br>Basic error handling and debugging concepts. | LO.3 |
| 3 | Working with data structures in Python | Lists, tuples, sets, and dictionaries.<br>Iteration and data access techniques.<br>Basic file input and output operations. | LO.3 |
| 4 | NumPy fundamentals | NumPy arrays and array creation methods.<br>Indexing, slicing, and reshaping arrays.<br>Vectorized operations and basic mathematical functions. | LO.2, LO.4 |
| 5 | Pandas fundamentals | Pandas Series and DataFrame structures.<br>Reading data from CSV and Excel files.<br>Basic selection, filtering, and column operations. | LO.2, LO.5 |
| 6 | Data manipulation with Pandas | Sorting, merging, and joining datasets.<br>Handling missing values and duplicates.<br>Data type conversion and formatting. | LO.5 |
| 7 | Integrated programming workflow | Combining Python, NumPy, and Pandas to build simple data manipulation scripts.<br>Automating repetitive data processing tasks. | LO.6 |

- Mathematic foundation for data science.
- Basic computer literacy is recommended. No prior programming experience is required.

### Comments

This micro-credential focuses exclusively on foundational Python programming and the basic use of NumPy and Pandas for structured data manipulation. It does not cover data analysis, statistical modeling, or machine learning, ensuring a clear focus on building essential programming competence for subsequent data science courses.
