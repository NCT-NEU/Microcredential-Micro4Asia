## Data cleaning and preprocessing with Python
<hr>

### MP Title

Data cleaning and preprocessing with Python  
- Class contact: 15 hours  
- Independent study: 30 hours

---

### MP Aim

Develop practical skills in cleaning, preparing, and transforming raw datasets into high-quality, structured data suitable for analytical and data mining tasks, using Python as the primary processing tool.

---

### Learning outcomes 

| LO code | Bloom Level | Category | Learning outcome |
|---------|-------------|----------|------------------|
| LO.1 | Understand | Knowledge | Explain common data quality issues and their impact on analytical outcomes. |
| LO.2 | Understand | Knowledge | Describe core principles and techniques of data cleaning and preprocessing. |
| LO.3 | Apply | Skills | Apply Python-based techniques to clean incomplete, inconsistent, and noisy data. |
| LO.4 | Apply | Skills | Transform raw data into structured and standardized formats. |
| LO.5 | Apply | Skills | Implement preprocessing techniques to improve data consistency and usability. |
| LO.6 | Analyze | Skills | Evaluate data quality before and after preprocessing. |
| LO.7 | Analyze | Skills | Assess the readiness of cleaned data for further data mining or analytical tasks. |

---

### Content

| Topic No. | Teaching topic | Content description | LO |
|-------|----------------|--------------------------------|---------|
| 1 | Introduction to data quality and preprocessing | concept of data quality and its role in data science.<br>types of data quality issues: missing, inconsistent, duplicated, noisy.<br>impact of poor-quality data on downstream tasks. | LO.1, LO.2 |
| 2 | Handling missing and inconsistent data | identification of missing values and abnormal entries.<br>imputation techniques and deletion strategies.<br>standardizing inconsistent formats. | LO.3 |
| 3 | Removing duplicates and noise | detecting duplicate records and outliers.<br>noise reduction strategies.<br>basic anomaly identification. | LO.3 |
| 4 | Data transformation and standardization | normalization and scaling techniques.<br>encoding categorical variables.<br>feature formatting and value transformation. | LO.4, LO.5 |
| 5 | Data restructuring and integration | reshaping data structures.<br>merging and joining datasets.<br>reorganizing variables and attributes. | LO.4, LO.5 |
| 6 | Automated preprocessing workflows | building reusable preprocessing pipelines using Python.<br>organizing step-by-step cleaning processes. | LO.5, LO.7 |
| 7 | Data quality evaluation | comparing data before and after preprocessing.<br>measuring improvements in consistency and completeness.<br>assessing readiness for data mining or analysis. | LO.6, LO.7 |

### Teaching and learning methods

| Teaching Method | Description | Related Learning Outcomes |
|----------------|-------------|---------------------------|
| Conceptual lectures & live demonstrations | introduces data quality concepts and preprocessing principles through structured explanation | LO.1, LO.2 |
| Guided hands-on coding practice | develops practical ability to clean and preprocess raw data using Python tools | LO.3, LO.4, LO.5 |
| Step-by-step workflow exercises | reinforces systematic implementation of preprocessing procedures | LO.3, LO.5 |
| Case-based learning (real datasets) | strengthens understanding through realistic data cleaning scenarios | LO.6, LO.7 |

Python libraries used in this module

- pandas – data cleaning and manipulation  
- numpy – numerical operations  
- scikit-learn – preprocessing utilities (scaling, encoding)  
- missingno – visualization of missing data structure  
- re – text cleaning and pattern normalization

### Comments

This micro-credential is dedicated exclusively to data cleaning and preprocessing, forming a critical foundation for data mining, machine learning, and analytical modelling modules. It ensures learners understand not only how to clean data, but also why preprocessing quality directly affects the reliability and validity of analytical results.
